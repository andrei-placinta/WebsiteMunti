# Sureanu Mountains Tourism Website

A multi-page tourism information website dedicated to the **Sureanu Mountains**, developed using HTML, CSS and JavaScript as part of an academic project.

The website presents tourist attractions, geographical characteristics, local wildlife, vegetation, accommodation information and travel resources through an organized and visually structured interface.

## Features

- Homepage presenting the Sureanu Mountains and their tourist attractions.
- Photo gallery featuring landscapes and locations from the region.
- Geographical information about the mountain range.
- Dedicated sections covering local vegetation, wildlife and tourism.
- Tourist guide with geographical information, maps and access routes.
- Accommodation information and visitor comments.
- Weather information with forecast charts and visual representations.
- Embedded YouTube video presentation.
- Bibliography page containing research sources and external references.
- Comment and newsletter subscription forms using SMTPJS.
- Multi-page navigation with dropdown menus.
- Responsive layout and mobile navigation.
- Google Analytics integration.

## Tech Stack

- **Frontend:** HTML5, CSS3
- **Scripting:** JavaScript
- **JavaScript Library:** jQuery
- **Icons:** Font Awesome 4.5.0
- **Analytics:** Google Analytics
- **Email Integration:** SMTPJS
- **Video Integration:** YouTube Embed
- **Website Template:** Arialogic by OS Templates

## Website Sections

### Homepage

Provides an introduction to the Sureanu Mountains, featuring tourist attractions, photographs, geographical information and navigation to the other website sections.

### Photo Gallery

Contains a collection of photographs showcasing mountain landscapes and locations from the Sureanu Mountains.

### Geographical Characteristics

Presents information about:

- Mountain vegetation and forest areas.
- Local wildlife and fauna.
- Hiking trails and tourism opportunities.
- Natural characteristics of the mountain range.

### Tourist Guide

Provides geographical information about the region, mountain peaks, surrounding areas, access routes and maps.

### Accommodation and Visitor Information

Includes information about accommodation options, local mountain cabins and visitor experiences.

The page also features comment and newsletter subscription forms connected through SMTPJS.

### Weather Information

Displays weather charts and visual information about temperature trends and precipitation forecasts for the Sureanu Mountains.

### Video Presentation

Includes an embedded YouTube video related to the Sureanu Mountains.

### Bibliography

Provides external references and research sources used to prepare the website content.

## Running Locally

### Requirements

- A modern web browser.
- Internet connection for externally hosted content and integrations.

### Setup

1. Download or clone the repository.

2. Open the project directory.

3. Open `index.html` in your web browser.

4. Navigate through the website using the main navigation menu.

5. Explore the different sections, including the photo gallery, tourist guide, geographical information, weather charts and video presentation.

**Note:** The website is primarily static and does not require a backend server or database. External integrations such as YouTube and SMTPJS require an internet connection and valid service configuration.

## Purpose

This academic project demonstrates practical knowledge of frontend web development, HTML structuring, CSS styling, JavaScript interactions, jQuery integration and the development of a multi-page informational website.

It also provides experience in organizing website content, integrating external services and creating a structured interface for presenting geographical and tourism-related information.
